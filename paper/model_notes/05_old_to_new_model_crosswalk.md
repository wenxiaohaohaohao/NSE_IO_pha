## 1. Purpose and authority

This file is the Phase 12 deletion and replacement ledger. It does not edit,
reinterpret, or silently reuse the locked manuscript. The precedence order is
the current user instruction, v1.2 correction, amendment v1.1, base execution
note, and only then the legacy manuscript and model notes as crosswalk
evidence.

The exhaustive occurrence-level evidence is
paper/model_rebuild/audit/phase12_legacy_occurrence_index.csv. It contains
1,242 rows, one for every regex-matched legacy occurrence, with source file, UTF-8 line
number, context role, enclosing equation/proposition label where present, and
the exact source line. The index is generated by
paper/model_rebuild/scripts/build_phase12_legacy_inventory.ps1 from the two
locked manuscript files and eleven named legacy model notes. The crosswalk
therefore separates:

1. an exhaustive, mechanically reproducible location inventory; and
2. the economic decision about deletion, retention, replacement, or
   quarantine recorded below.

The legacy sources remain read-only. Phase 18 may implement only the actions
listed here and only after its separate manuscript-integration authorization.
